# Мани 0.2 — учёт расходов и доходов

Веб-приложение (PWA) для iPhone: ставится на экран «Домой» из Safari, работает без интернета, данные хранятся только на телефоне.

## Установка на iPhone
1. Открыть адрес приложения в **Safari**.
2. «Поделиться» → «На экран „Домой“» → «Добавить».
3. Открывать значком «Мани». После первого открытия работает без сети.

## Публикация (бесплатно, GitHub Pages)
- **Способ А (без компьютерных навыков):** создать публичный репозиторий `mani` на github.com → Add file → Upload files → загрузить содержимое папки из `mani-site.zip` → Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)`. Адрес: `https://<логин>.github.io/mani/`.
- **Способ Б (исходники):** залить этот проект в репозиторий, Settings → Pages → Source: *GitHub Actions*. Каждый push в `main` прогоняет тесты, собирает и публикует.

## Разработка
- `npm install`, `npm run dev` — локально
- `npm test` — тесты разбора фраз, дат, счетов, базы (остатки, правка, сверка, копия)
- `npm run build` — сборка в `dist/`

## Структура
- `src/lib/parser.ts` — сумма, тип, категория (из v0.1)
- `src/lib/dates.ts` — «вчера», «в пятницу», «3 октября»
- `src/lib/request.ts` — фраза → черновик операции (счёт, дата, заметка); в v0.4 заменяется встроенной моделью
- `src/db.ts` — IndexedDB (Dexie): операции, счета, категории, остатки, сверка, резервная копия, CSV
- `src/screens/` — Главная, Счета, История, Статистика, Настройки
